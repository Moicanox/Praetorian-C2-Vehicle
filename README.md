**Praetorian C2 Vehicle** is a lightweight **Command & Control (C2)** software platform designed for **vehicle-mounted operations, tactical environments and constrained communication networks**.

The project was created to provide a responsive C2 workstation capable of operating on rugged and older-generation vehicle computers while maintaining interoperability with the **TAK ecosystem**, including **ATAK, WinTAK and TAK Server**.

Praetorian is **not intended to replace WinTAK**.

Its objective is to provide an alternative vehicle-oriented C2 solution for operational environments where computing resources, communications bandwidth or network topology make conventional solutions difficult to deploy.

> **Built for vehicle-mounted Command & Control.**
> **Optimized for tactical and constrained networks.**
> **Designed to operate when conventional solutions cannot.**

* **Cursor on Target (CoT) interoperability**
* **ATAK interoperability**
* **WinTAK interoperability**

* **MIL-STD-4609 video support**

* **And much more**

## Designed for Constrained Tactical Networks

A major design objective of Praetorian C2 Vehicle is operation over **limited-bandwidth tactical IP networks**.

The platform is designed for environments where available bandwidth may be significantly lower than conventional LAN, Wi-Fi or broadband networks.

This includes tactical communications using technologies and waveforms associated with environments such as:

* **HF**
* **TACSAT**
* **Narrowband tactical IP networks**
* **Radio-based vehicle networks**
* **Constrained or intermittent communication links**

Praetorian provides dedicated communication workflows intended to reduce unnecessary network traffic while maintaining operational awareness between connected nodes.

## LEGIO Mode

**LEGIO Mode** is a dedicated Praetorian operating mode designed for communication between C2 nodes over tactical radio networks and constrained IP links.

It allows Praetorian systems to exchange operational information and maintain **situational awareness** through radio communication vectors where conventional high-bandwidth network architectures may not be practical.

## TAK Ecosystem

Praetorian C2 Vehicle is designed to remain interoperable with the wider **TAK ecosystem**.

Operational information can be exchanged with compatible TAK systems using **Cursor on Target (CoT)** and related interoperability mechanisms.

The objective is to allow vehicle-mounted Praetorian workstations, ATAK operators, WinTAK operators and TAK Server infrastructure to participate in the same operational environment.

# Praetorian Tools — ATAK Plugin

The Praetorian ecosystem also includes **Praetorian Tools**, a dedicated plugin for **ATAK-CIV**.

Praetorian Tools extends ATAK with additional tactical functions and provides interoperability with Praetorian C2 Vehicle.

Current tools include:

### TAK Logistic

Dedicated functionality for creating and managing logistics information directly from ATAK.

It is designed to simplify the preparation and exchange of logistics reports between operators and Praetorian C2 Vehicle systems.

### Format Messages

Allows ATAK operators to create and exchange structured **ATP formatted tactical messages**.

The function is designed for interoperability with Praetorian C2 Vehicle and standardized operational workflows.

# Offline Operations

Praetorian C2 Vehicle is designed to support operational environments where permanent Internet connectivity cannot be assumed.

Offline mapping resources can be prepared for local use, allowing the C2 workstation to maintain map visualization and operational functionality when disconnected from conventional Internet services.

# Project Philosophy

Praetorian C2 Vehicle was developed around three primary objectives:

### Lightweight

Suitable for vehicle-mounted rugged computers, including older-generation systems where heavier C2 applications may consume significant computing resources.

### Interoperable

Designed to exchange tactical information with the TAK ecosystem rather than creating an isolated proprietary operational environment.

### Tactical Network Oriented

Designed with constrained tactical radio networks in mind, where bandwidth, latency and network topology require greater control over the amount and type of information transmitted.
