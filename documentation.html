Requirements

Lightweight by design.

Praetorian C2 Vehicle runs on Windows 10 and Windows 11 systems without requiring recent hardware or a dedicated graphics card.

OS

Windows 10 and 11

Compatible with 64-bit x64 editions of Microsoft Windows 10 and Windows 11.

CPU

Modest system resources

Designed to run on older x64 processors and systems with limited RAM. Resource use increases with active maps, terrain analysis, video streams and mission data.

GPU

Integrated graphics

An integrated graphics adapter is sufficient for normal operation; a dedicated GPU is not required. The interface supports both pointer and touchscreen input.

DSK

Storage

The current complete installation occupies approximately 710 MB. Allow additional local space for offline maps, DTED terrain datasets, inbox content and mission files.

PKG

Self-contained deployment

The Windows package includes Java 17, GStreamer 1.0 and the required Microsoft Visual C++ runtime libraries. No separate runtime installation is required.

I/O

Optional integrations

Network interfaces, serial NMEA devices, cameras and video hardware are required only for the corresponding operational functions. Offline map workflows can operate without an Internet connection.
